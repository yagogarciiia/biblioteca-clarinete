# Biblioteca de repertorio orquestral · Clarinete

Biblioteca web/PWA de repertorio orquestral para clarinete, clarinete baixo e requinto, baseada nas programacións de 2.º e 3.º do CSM da Coruña e investigación documental complementaria.

## Contido

- 35 fichas revisadas.
- 96 extractos.
- Localización no Orchester-Probespiel EP8661 cando corresponde.
- Contexto histórico e musical.
- Papel do clarinete.
- Dificultades técnicas e interpretativas.
- Gravacións de referencia.
- Partituras e materiais de estudo.
- Notas persoais gardadas só no dispositivo.

## PWA / iPad

A web está preparada como PWA. En iPad:

1. Abrir a web en Safari.
2. Compartir.
3. Engadir á pantalla de inicio.
4. Activar «Abrir como app web» se aparece a opción.

A interface e o contido integrado poden abrirse sen conexión unha vez cargados. Os recursos externos (YouTube, IMSLP, Apple Music, PDFs de terceiros, etc.) requiren conexión.

As anotacións persoais utilízanse mediante localStorage e **non se publican en GitHub**. A biblioteca permite exportalas/importalas en JSON.
